# FortSymb

FortSymb is an experimental symbolic executor for a subset of Fortran 90. It explores program paths with symbolic inputs and uses the What4 interface to Z3
to check runtime safety conditions and user assertions. When an obligation can fail, FortSymb reports a counterexample.

FortSymb is under development. It does not yet implement the complete Fortran language and should not be treated as a production verifier.

## Features

FortSymb currently supports:

- Integer, real and logical scalar values
- Symbolic values introduced by reads
- Arithmetic, comparison and logical expressions
- Scalar and multidimensional arrays and sections
- `if`, `else if`, `else` and `select case` control flow
- Bounded `do` and `do while` loop exploration
- Functions, subroutines, argument intents and bounded recursion

## Requirements

- Windows (for now)
- [Haskell Stack](https://docs.haskellstack.org/)

The package includes a reduced 32-bit Z3 4.8.12 runtime, so Z3 does not need to
be installed separately.

## Building

From the repository root:

```console
stack install
```

Stack installs the `fortsymb` executable into the directory reported by:

```console
stack path --local-bin
```

Add that directory to your Windows `PATH` if it is not already present.

## Usage

Run FortSymb with a Fortran source file:

```console
fortsymb path\to\program.f90
```

The command-line interface is:

```text
fortsymb FILE [--no-user-asserts] [--max-unroll N]
              [--max-call-depth N]
              [--show-valid-internal-obligations]
```

Options:

- `--no-user-asserts` disables proof obligations generated from user
  assertions.
- `--max-unroll N` sets the maximum number of `do`-loop unrollings (defaults to `10`).
- `--max-call-depth N` sets the maximum nested procedure-call depth (defaults to `10`).
- `--show-valid-internal-obligations` includes successful internal (non-user) obligations in the result.
- `-h` or `--help` displays command-line help.

## Assertions

Add an assertion using a specially formatted Fortran comment:

```fortran
program bounds_example
    integer :: values(5) = [10, 20, 30, 40, 50]
    integer :: i

    read *, i
    !@assert values(i) >= 10
end program bounds_example
```

The assertion marker must be written as `!@assert ` followed by a logical Fortran expression. Leading indentation is allowed.


## Proof obligations

FortSymb generates the following obligation kinds:

- `UserAssertion` - obligation generated by `!@assert`.
- `DivByZero`: the divisor of an integer or real division must be non-zero.
- `ArrayBounds`: every array element or section subscript must fall within its declared dimension bounds.
- `ArrayShape`: array ranks and extents must be compatible where an assignment or procedure argument requires matching shapes.
- `IncrementStepNonZero`: the increment of a counted `do` loop must be non-zero.
- `ArraySectionStrideNonZero`: the stride in an array section triplet must be non-zero.
- `UninitialisedRead`: a scalar value or array element must be initialised before it is read.

Each obligation is checked under the path conditions that hold at the source location where it was generated.


## Future work

The main planned areas for further development are:

- Complete array support, including implied-`do` and nested constructors, array-valued constructor elements, reshaping, element-wise arithmetic and assumed-shape arrays.
- Broaden procedure and program support with modules, external and general procedure calls, additional intrinsic functions and named control constructs.
- Add more Fortran types and language facilities, particularly character and complex values, derived types and pointers.
- Make solver discovery and packaging portable beyond the current bundled Windows Z3 executable.
